# Build Instructions — Petualangan Kode Rubina

## Quick Start

```bash
npm install
npm run build
npx cap sync
```

## Opening Android Studio

```bash
npx cap open android
```

## Building APK (Debug)

```bash
cd android && ./gradlew assembleDebug
```

The APK will be at: `android/app/build/outputs/apk/debug/app-debug.apk`

## Building APK (Release)

```bash
cd android && ./gradlew assembleRelease
```

**Note:** For release builds, you'll need to configure signing in `android/app/build.gradle` and update `appId` in `capacitor.config.ts`.

## Syncing Web Assets

After making changes to the web code:

```bash
npm run build
npx cap sync android
```

## Troubleshooting

### Build fails with "Could not find com.android.tools.build:gradle"

Ensure you have Android Studio installed and SDK configured. Check `android/gradle.properties` for the correct path.

### App crashes on launch

Check `android/app/src/main/assets/capacitor.config.json` matches your web build output.

### Icons not showing

Ensure icons exist at `public/icons/` and are referenced in `public/manifest.json`.
